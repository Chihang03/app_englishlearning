# 四级词义核查记录（2026-10）

本次按项目现有词典快照处理 `cet4` 词表，使用项目支持的 Luna 低推理模式（`gpt-6-luna` / `low`），按词性、中文释义、英文定义、英文例句及现有中文翻译，单词级结构化成批分析。模型结果经既有 schema 和逐词语义完整性校验后写入 `backend/data/semantic_reviews.json`；不可靠项以 `manual` 保存为待核查提案，数据库同步时不覆盖原义项。

## 覆盖范围与结果

- 四级词表登记 4,019 个词，其中 3,940 个有可核查词典义项；其余 79 个没有词典义项记录，本次未编造内容。
- 3,940 个有源义项的词均有一条来源指纹匹配的核查记录。
- 3,123 个词通过核查，可用于标准化与核心义项合并；817 个词因映射、词性或翻译证据不完整而保留原始数据、标为待核查。
- 结果保留来源词义快照、来源字段与义项映射；英文定义和原例句仍可追溯。中文释义为学习展示主字段，例句译文按义项和句境核对。
- dry-run 在隔离数据库报告 `applied=3,122`、`manual=817`、`stale=1`。一个已有核心义项若直接合并会拆分旧核心，系统按保护规则跳过并保留旧数据，需专门历史迁移才能处理；因此实际可应用数比通过核查数少 1。

## 安全与复核

最终数据包中的每个词均与本次快照源指纹一致，并通过 `validate_word`；覆盖检查为 3,940/3,940，无缺词或额外词。数据库 dry-run 在内存副本中执行真实同步路径及外键检查，不写入学习记录。自动核查不能替代人工审定，`manual` 词及被历史核心保护规则跳过的词应在后续复核中处理。

## 复现

```bash
PYTHONPATH=backend backend/.venv/bin/python backend/scripts/semantic_exchange.py apply-db \
  --db /path/to/vocabulary.db \
  --bundle backend/data/semantic_reviews.json --dry-run
```

对目标数据库先执行 dry-run；确认其源数据指纹与本次快照相符后，再按 `docs/semantic-review-workflow.md` 的流程备份并应用。新增或更改源词义会因指纹变化而要求重新核查，不会套用旧提案。
