## 页面路由

前端学习者页面与管理员页面使用 hash 路由。登录与注册由认证状态驱动。服务端的 `/api/` 接口与前端 hash 分开处理。

| 页面 | URL 或状态 | 主要入口与返回 | 代码 |
|---|---|---|---|
| 登录、注册、Passkey 登录 | 未认证状态 | 打开应用进入认证界面 | AuthScreen.tsx、App.tsx |
| 首页 | `/#home`，空 hash 默认首页 | 登录、底部首页导航 | App.tsx |
| 例句学习 | `/#study` | 开始学习、通知入口；返回首页 | App.tsx、StudyCard.tsx、StudyDeck.tsx |
| 设置 | `/#settings` | 底部设置导航；返回首页 | App.tsx |
| 学习日历 | `/#learning-calendar` | 首页日历入口；返回首页 | LearningCalendar.tsx、App.tsx |
| 词汇水平测验 | `/#assessment` | 设置、全新账号首页；返回设置 | Assessment.tsx |
| 不再学习管理 | `/#muted-words` | 设置；返回设置 | MutedWords.tsx |
| 词库详情 | `/#word-list/{编码后的词库ID}` | 设置中的词库；返回设置 | App.tsx |
| 管理概览 | `/#admin` | 管理员登录后进入 | AdminDashboard.tsx |
| 管理用户列表 | `/#admin/users` | 管理概览 | AdminDashboard.tsx、AdminUsers.tsx |
| 管理用户详情 | `/#admin/users/{id}` | 用户列表 | AdminUsers.tsx |
| 管理反馈列表 | `/#admin/reports` | 管理概览 | AdminReports.tsx |
| 管理反馈详情 | `/#admin/reports/{id}` | 反馈列表 | AdminReports.tsx |
| 更多词义、报告错误 | 学习工具状态，无独立 hash | 学习页工具菜单 | StudyTools.tsx |
| 词典查询接口 | `/api/dictionary/{word}`，当前无独立查词页面 | 通过 API 提供词典数据，学习中查阅使用更多词义工具 | 后端 lexicon.rs、前端 StudyTools.tsx |

前端路径均位于 `frontend/src/`。设置子页共享页头位于 `Navigation.tsx`。UI 状态不应凭空写成独立 HTTP 页面。

## 静态资源与内部入口

| 路径 | 作用 | 访问 |
|---|---|---|
| `/` | 前端入口 | 公开，页面内容受登录状态控制 |
| `/assets/*` | 构建后的脚本、样式与图片 | 公开静态资源 |
| `/version.json` | 前端发布版本检查 | 公开静态资源 |
| `/manifest.webmanifest` | PWA 安装信息 | 公开静态资源 |
| `/sw.js` | Service Worker | 公开静态资源，实际缓存规则见实现 |
| `/internal/ready` | 原生服务就绪检查 | 仅内部，Nginx 公网入口拒绝 |

## 路由维护规则

新增或删除页面时同步页面表，调整权限与数据写入时同步 API 表。基础冻结接口清单位于 `rust/fixtures/routes.json`，测验清单位于 `rust/fixtures/assessment-routes.json`，运行行为以原生入口为准。检查当前项目时先阅读构想和对应模块，再沿表中的代码入口定位实现。
