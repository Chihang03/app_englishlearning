# 词汇水平测验与动态学习

## 使用

设置 → 词汇水平测验。全新账号首页也有入口，用户仍可直接开始普通学习。

新测验包含 32–40 道词义理解题，按正常作答约 5–6 分钟的题量设计，不设倒计时或强制交卷。前八题跨层定位，随后保证六层各至少四题，再根据网格贝叶斯信息量选题。服务端保存每次签发、选项顺序和答案，支持退出恢复、跨设备读取与相同答案幂等重试。测验期间不显示正确答案。

新测验不再签发提取题，结果用于词汇理解层级与学习难度排序。它不测量拼写、写作或完整词汇产出能力，也不提供精确词汇量或 CEFR 认证。试测、重测与独立基准验证仍需真实使用者参与，模拟不能替代这些证据。

“按此水平开始”才启用能力档案。学习方式和基础 800 词开关独立保存、同时显示，切换方式不修改排除偏好。手动不再学习的词不参与测验或学习，也不被当成已认识。测验不受基础 800 开关限制，通用测验也不受课程选择限制；日常新增学习继续限制在所选词库和本账号历史私有内容内。

## 内容与模型

题库保留 600 条不可变题目记录：480 道理解题供新测验使用，120 道旧提取题仅供旧版未完成测验继续作答。六层各有 80 道理解题。词义由项目编写，未复制 VLT、VST、LexTALE 或 EVP 题目。题库状态为 authored，初始难度是待实测的设计先验，不是已经获得专家常模验证的参数。

```sh
python3 backend/scripts/assessment/build_bank.py --check
```

理解题使用四选猜测下限 0.25、固定斜率，能力网格 -6 至 6，正态初始先验。至少 32 道理解题、每层至少四题、后验标准差不大于 0.6 时允许结束，否则最多 40 题。全对全错会保留边界提示；题池耗尽则标记证据不足，禁止应用。

同一次测试不重复词头，近期七天的学习内容和三十天内其他测验已签发词头不重复。排除过多时宁可返回不足，不临时扩大题池到受排除内容。题目 ID、词头身份和答案索引不下发，服务端只下发本题题型、题干、选项和顺序号。

学习难度只在中文教学含义与原创含义完全一致时绑定到 learning_unit_id，标记为未校准；其他义项保持词频先验。词频不代表义项真实难度，未知义项不自动继承已掌握判断。

## 学习与复习

按水平模式以 70% 能力附近、20% 基础抽查、10% 挑战的目标偏移选择新单元，按独立首次回答计数轮换。到期复习、巩固和新词使用同一份有效暂缓集合。底层 SRS、历史和原复习日期不改写；当前未提交题目在排除生效后作废，旧设备提交返回 409，不记错。可学新词和即刻复习只计实际可发任务。词库原始总量、历史接触量仍是目录和历史统计，暂缓不算掌握。

日常更新只读取新学习单元的首次无提示、无朗读、无答案曝光作答。至少 50 条、30 个不同单词、三个账号本地学习日，才进行一次最多 0.15 的工作难度调整，相对正式测验锚点累计不超过 0.75。更新不把有选择偏差的学习数据冒充正式 IRT 校准，不提高估计精度。旧复习答错、同词重试和手动排除不直接改变能力。

短确认暂缓已启用，不依赖全局校准开关。所有队列、统计和提醒都读取同一个、账号隔离的资格集合；带主键的集合仅存于 SQLite TEMP，主库只读连接仍以只读方式打开。候选池耗尽不绕过过滤返回原始词池。

### 标准复习与长期熟记

日常独立答对只交给原有记忆模型更新稳定性、下次复习日期和长期熟记状态。已进入标准复习的学习单元不参与水平暂缓，短确认通过也不能屏蔽已安排的复习。

旧版根据两天、两个任务上下文的正确回答生成的 personal_confirmation 暂缓不再生效。原有 SRS 状态、历史和复习日期用于恢复队列，不批量标记熟记，也不重算历史。

### 分层短确认

结果页选择“确认可跳过的范围”，进入独立的 12 题词义理解流程，词头互不重复。初始产品规则为理解至少 11/12；它授权的是有限范围的词义理解暂缓，不是提取能力认证。未通过、题池不足、结果超过七天未应用，均不授予暂缓。

通过后，只对尚未进入标准复习、原创题库中本层的常用含义与教学含义完全一致的单元建立暂缓。不会扩大到整个词头、所有派生词或任意词频排名以内。近期仍未解决的独立答错和本次确认答错的具体单元保留。暂缓分散为 7–14 天，不超过确认完成后 14 天。

这是有复核、可恢复的教学策略，不是经过大样本校准的 95% 掌握概率，也不把本层全部英语词汇认定为已知。通过结果显示可暂缓范围，应用后显示实际有效暂缓数。按水平暂缓的内容可以展开查看并逐项“继续学习”，不会被后续自动刷新再次暂缓。

基础 800 排除和手动不再学习优先于自动策略，自动暂缓计数不重复计算已被这两项排除的内容。关闭按水平模式后，自动暂缓失效，但用户排除偏好保持不变。词典始终可查。

## 数据和发布

新会话使用协议标记 `vocab-recognition-v2`；旧 `vocab-grid-v1` 会话继续使用原题量、提取题和通过标准，已完成结果不重算。应用能力档案时保留对应会话的协议版本。此次不增加数据库字段或改写原题库。

主库继续使用 v22，保留 assessment_schema=1，并新增 readiness_schema=2 的附加表及测验类型字段。旧程序忽略附加表，代码回退无需降级主版本，也不会覆盖部署后的新学习记录；旧程序不理解新版个人暂缓，回退时其队列可能恢复到旧策略范围。HTTP 启动不迁移，维护 CLI 必须先做一致性备份。

```sh
englishctl assessment-install --database /data/vocabulary.db --backup /backup/before-assessment.db
```

首次升级会修复旧版按水平模式自动关闭、且保存值明确为开启的基础词偏好；后续安装不重复修复，以保留新版中用户明确关闭的选择。安装拒绝覆盖备份，也拒绝用同一题目 ID 覆盖不同题目。题目修改须使用新 ID／版本。发布脚本在暂停服务、保存原有一致性备份后安装扩展，再切换发布。失败切回旧二进制和静态文件，保留当前数据库和所有已提交的新数据。

API：

| 方法 | 路径 | 用途 |
|---|---|---|
| POST | /api/assessments | 开始或恢复唯一活跃测验 |
| GET | /api/assessments/{id} | 恢复进度或读取结果 |
| POST | /api/assessments/{id}/answers | 按 sequence 提交，原子评分和发下一题 |
| POST | /api/assessments/{id}/abandon | 放弃，保留审计记录 |
| POST | /api/assessments/{id}/apply | 应用充分结果，相同操作幂等 |
| GET | /api/proficiency | 能力档案、学习模式和有效暂缓数 |
| POST | /api/proficiency/confirmations | 开始或恢复指定层级的短确认 |
| GET | /api/proficiency/readiness | 本账号有效暂缓单元及有效期 |
| POST | /api/proficiency/readiness | 指定 learning_unit_id 继续学习，保存用户覆盖 |
| PATCH | /api/proficiency/mode | adaptive 或 frequency |

所有接口要求学习账号认证，路径 ID 必须归属当前用户；管理员不能使用学习路由。未签发顺序、修改已评分答案或应用旧结果会被拒绝。返回 no-store，测验作答不进入 IndexedDB 展示缓存。

## 诊断、校准与启用门槛

```sh
python3 backend/scripts/assessment/analyze.py --simulate --output /tmp/simulation.json
python3 backend/scripts/assessment/analyze.py --database /data/vocabulary.db --output /tmp/item-diagnostics.json
```

分析只读，输出按题聚合，不导出账号、会话令牌、密码或作答原文。按参与者留出验证，能力估计去掉当前题；每题训练至少 100 人、验证至少 30 人后才提出诊断难度。该工具不会自动替换现有题目参数或启用暂缓。

模拟固定随机种子，七个能力点各 30 名模拟参与者。模型一致模拟只检查实现和边界表现，不构成真实用户校准；初始先验在能力边界会产生收缩，需要保守解读。

原生 CLI 可以校验或导入独立参照验证的难度元数据：

```sh
englishctl assessment-calibrate --database /data/vocabulary.db --input /data/reference-report.json --dry-run
```

正式启用还必须传入 `--backup /backup/before-calibration.db`；备份拒绝覆盖。

报告包含 model、version、independent_reference、training_participants、units、validation。units 每条包含 unit_id、difficulty、reviewed_common_sense、training_responses；validation 每条包含 participant、unit_id、mean、sd、known。输入参与者使用稳定的脱敏标识。

启用要求：至少 50 个训练参与者；训练和验证人员不重叠；至少 30 个验证参与者和 200 个预测暂缓判断；每个义项至少 100 个训练响应、100 个独立验证暂缓判断；总体及每个义项的误暂缓率 Wilson 95% 上界均不超过 5%。义项必须是审核后的常用含义，不能按词头批量授权全部含义。生产目前没有此类独立校准证据。校准产物可用于难度排序改进，短确认的暂缓规则独立运行，不假称经过全局概率校准。

## 验证边界

原生隔离集成测试覆盖极端作答、恢复、重试、跨账号、题目泄露、池耗尽、学习单元排序、手动排除、SRS 不变和备份拒绝覆盖；新增覆盖真实暂缓、到期任务恢复、部分义项不虚增掌握、不同账号复用读取连接、证据过期和重复安装保留新偏好。浏览器测试覆盖新测验全选择题、手机尺寸、旧测验 IME、断线后的重试、结果应用和设置切换。五六分钟是题量预算，尚未经过真实用户计时验证。Chromium 手机模拟不等同于真实 iPhone Safari、软键盘或安装后的 PWA 验收。
