# 词汇水平测验与动态学习

## 使用

设置 → 词汇水平测验。全新账号首页也有入口，用户仍可直接开始普通学习。

测验包含 24–36 道词义理解题和 4 道带首字母及长度线索的提取题，共 28–40 题。前八题跨层定位，随后保留六层最低覆盖，再根据网格贝叶斯信息量选题。服务端保存每次签发、选项顺序和答案，支持退出恢复、跨设备读取与相同答案幂等重试。测验期间不显示正确答案。

理解和线索提取分别报告，后者不是自由写作或完整词汇产出能力。结果给出内部词汇层级和估计范围，不提供精确词汇量或 CEFR 认证。试测、重测与独立基准验证仍需真实使用者参与，模拟不能替代这些证据。

“按此水平开始”才启用能力档案。设置可切回按词频学习，原基础 800 词开关值会恢复。手动不再学习的词不参与测验或学习，也不被当成已认识。测验不受基础 800 开关限制，通用测验也不受课程选择限制；日常新增学习继续限制在所选词库和本账号历史私有内容内。

## 内容与模型

原创题库共 600 题：480 道理解题、120 道线索提取题。六层各有 80 道理解题和 20 道提取题。词义由项目编写，未复制 VLT、VST、LexTALE 或 EVP 题目。题库状态为 authored，初始难度是待实测的设计先验，不是已经获得专家常模验证的参数。

```sh
python3 backend/scripts/assessment/build_bank.py --check
```

理解题使用四选猜测下限 0.25、固定斜率，能力网格 -6 至 6，正态初始先验。至少 24 道理解题、每层至少两题、后验标准差不大于 0.6 时允许结束理解部分，否则最多 36 题，再进行四道提取。全对全错会保留边界提示；题池耗尽则标记证据不足，禁止应用。

同一次测试不重复词头，近期七天的学习内容和三十天内其他测验已签发词头不重复。排除过多时宁可返回不足，不临时扩大题池到受排除内容。题目 ID、词头身份和答案索引不下发，服务端只下发本题题型、题干、选项和顺序号。

学习难度只在中文教学含义与原创含义完全一致时绑定到 learning_unit_id，标记为未校准；其他义项保持词频先验。词频不代表义项真实难度，未知义项不自动继承已掌握判断。

## 学习与复习

按水平模式以 70% 能力附近、20% 基础抽查、10% 挑战的目标偏移选择新单元，按独立首次回答计数轮换。到期复习、当前题目、巩固与 FSRS 不改写。可学新词数仍表示完整可学池，不是测验推定的已掌握词数。

日常更新只读取新学习单元的首次无提示、无朗读、无答案曝光作答。至少 50 条、30 个不同单词、三个账号本地学习日，才进行一次最多 0.15 的工作难度调整，相对正式测验锚点累计不超过 0.75。更新不把有选择偏差的学习数据冒充正式 IRT 校准，不提高估计精度。旧复习答错、同词重试和手动排除不直接改变能力。

自动暂缓默认关闭。完成独立验证后，只有获得审核和校准版本的具体义项，且保守知识概率至少 0.95，才可在新词排序中暂缓；候选池全部暂缓时仍可回到完整池。暂缓不计作熟记、不删除任务，也不隐藏词典内容。不会因一次测验取消已安排的复习。

## 数据和发布

主库继续使用 v22，新增 assessment_schema=1 的独立附加表。旧程序忽略附加表，代码回退无需降级主版本，也不会覆盖部署后的新学习记录。HTTP 启动不迁移，维护 CLI 必须先做一致性备份。

```sh
englishctl assessment-install --database /data/vocabulary.db --backup /backup/before-assessment.db
```

安装拒绝覆盖备份，也拒绝用同一题目 ID 覆盖不同题目。题目修改须使用新 ID／版本。发布脚本在暂停服务、保存原有一致性备份后安装扩展，再切换发布。失败切回旧二进制和静态文件，保留当前数据库和所有已提交的新数据。

API：

| 方法 | 路径 | 用途 |
|---|---|---|
| POST | /api/assessments | 开始或恢复唯一活跃测验 |
| GET | /api/assessments/{id} | 恢复进度或读取结果 |
| POST | /api/assessments/{id}/answers | 按 sequence 提交，原子评分和发下一题 |
| POST | /api/assessments/{id}/abandon | 放弃，保留审计记录 |
| POST | /api/assessments/{id}/apply | 应用充分结果，相同操作幂等 |
| GET | /api/proficiency | 能力档案与学习模式 |
| PATCH | /api/proficiency/mode | adaptive 或 frequency |

所有接口要求学习账号认证，路径 ID 必须归属当前用户；管理员不能使用学习路由。未签发顺序、修改已评分答案或应用旧结果会被拒绝。返回 no-store，测验作答不进入 IndexedDB 展示缓存。

## 诊断、校准与启用门槛

```sh
python3 backend/scripts/assessment/analyze.py --simulate --output /tmp/simulation.json
python3 backend/scripts/assessment/analyze.py --database /data/vocabulary.db --output /tmp/item-diagnostics.json
```

分析只读，输出按题聚合，不导出账号、会话令牌、密码或作答原文。按参与者留出验证，能力估计去掉当前题；每题训练至少 100 人、验证至少 30 人后才提出诊断难度。该工具不会自动替换现有题目参数或启用暂缓。

模拟固定随机种子，七个能力点各 30 名模拟参与者。模型一致模拟只检查实现和边界表现，不构成真实用户校准；初始先验在能力边界会产生收缩，需要保守解读。

原生 CLI 可以校验或导入独立参照验证的义项元数据：

```sh
englishctl assessment-calibrate --database /data/vocabulary.db --input /data/reference-report.json --dry-run
```

正式启用还必须传入 `--backup /backup/before-calibration.db`；备份拒绝覆盖。

报告包含 model、version、independent_reference、training_participants、units、validation。units 每条包含 unit_id、difficulty、reviewed_common_sense、training_responses；validation 每条包含 participant、unit_id、mean、sd、known。输入参与者使用稳定的脱敏标识。

启用要求：至少 50 个训练参与者；训练和验证人员不重叠；至少 30 个验证参与者和 200 个预测暂缓判断；每个义项至少 100 个训练响应、100 个独立验证暂缓判断；总体及每个义项的误暂缓率 Wilson 95% 上界均不超过 5%。义项必须是审核后的常用含义，不能按词头批量授权全部含义。生产当前没有此类独立证据，保持关闭。

## 验证边界

原生隔离集成测试覆盖极端作答、恢复、重试、跨账号、题目泄露、池耗尽、学习单元排序、手动排除、SRS 不变和备份拒绝覆盖。浏览器测试覆盖手机尺寸、IME、断线后的重试、结果应用和设置切换。Chromium 手机模拟不等同于真实 iPhone Safari、软键盘或安装后的 PWA 验收。
