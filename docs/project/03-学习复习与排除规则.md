# 学习、复习与排除规则

## 一次正常学习

服务端选择符合账号范围的学习单元并签发 attempt_id。前端显示固定例句的挖空和当前含义。提交后服务端校验账号、题目和回答，记录历史，更新对应单元的记忆状态，返回反馈。

独立作答要求正确且未使用提示、朗读或答案曝光。提示和更多词义的曝光在服务端记录，跨刷新、跨设备继续生效。错误后的纠正用于完成当前回合，复习模型按实际作答证据更新。学习页复用 InlineAnswer 和 StudyCard，键盘输入、中文输入法组合输入、手势回看与异步提交要共同验证。

## 新内容的顺序

新增学习先派发核心义，再派发扩展义。所选范围内的核心义都已开始学习后，扩展义才进入可学范围，并计入可学新词、尚未学习的义项和整词统计。已经学习的单元无论属于哪一类，都继续按原计划复习和统计。按词频与按水平两种方式都遵守这一顺序，各自的排序规则在同一类内部生效。

整词掌握和长期熟记按当前范围内的单元判定，即核心义加上已经开始学习的单元。词库详情的熟记数按同一口径计算。核心义的划分见[词库与内容模型](02-词库与内容模型.md)。

## 复习与长期熟记

记忆模型根据经过时间及独立作答更新难度和稳定性，以约 80% 目标回忆概率求复习间隔。模型使用 UTC 时间，计划和日统计按账号时区呈现。

本次独立答对后，模型估计未来 180 天的个人回忆概率达到 80%，单元进入 Mature。当前模型状态成熟的单元按 180 天进行抽查。失败或提示后的学习依照原调度规则恢复。整个词的长期熟记统计要求它的有效学习单元达到成熟条件。

个人遗忘速度校准采用有界系数，至少 150 个有效预测样本、20 个学习单元、跨度 30 天后才尝试评估，按时间划分训练与验证，达到损失改善门槛才采用。具体参数和回退见 README 的动态记忆部分。

## 四种范围控制

| 规则 | 用户入口或证据 | 作用范围 | 恢复方式 |
|---|---|---|---|
| 词库选择 | 设置中的词库选择 | 新增学习 | 重新选择词库 |
| 基础词排除 | 设置开关“跳过基础词”，词频规则见下 | 新词、复习、巩固及相应计数 | 关闭开关 |
| 不再学习 | 用户对具体词头的主动操作 | 该账号下该词的各义项 | 不再学习管理页恢复 |
| 水平暂缓 | 通过并应用分层短确认 | 尚未进入标准复习的匹配义项 | 到期或主动“继续学习” |

基础词按使用频率判定，取代原先的 NGSL 前 800 词头规则：

- 词频：wordfreq Zipf 值不低于 4.9 的词头，约 1,000 个，覆盖冠词、介词、连词、常见动词以及 dog、hot、mom 这类日常词。词频数据来自 `backend/data/word_frequencies.json`，对所有词库一致生效。
- 代词形式：me、my、mine、himself、these、whose 等宾格、所有格、反身和复数形式，只在义项本身是代词、限定词或冠词时排除，mine（矿）这类独立含义保持可学。
- 封闭类补充：be、have、do 的变化形式，better、best、worse、worst，以及基础数词和序数词，不论词频一律排除。

按拼写的词频判定会把高频拼写的全部义项一起排除，例如 found（建立）、left（左边）、means（方法）。原规则中词频低于 4.9 的 NGSL 词头（如 achieve、establish、occur、depend）恢复为可学。阈值是 `backend/app/learning_filters.py` 的 `BASIC_ZIPF_CENT`，补充清单是 `BASIC_SUPPLEMENT`；修改规则或更新词频数据后，用 `export_rust_reference.py` 重新生成 `content_index.sql` 和 `sql.json`。设置项在接口中的键名仍为 `skip_basic_600`。

通过注册页创建的新账号由前端写入“跳过基础词”为开启，新手引导最后一步和设置页都可以关闭。服务端对没有保存过该偏好的账号仍按关闭处理，已有账号保持原选择。

各项选择独立保存。切换按词频学习与按水平调整时，基础词排除偏好保持用户所选值。排除只改变可派发任务和相应统计，历史记录继续保存。

## 统计口径

统计由 `metrics.sql` 和 `study.rs` 的 `stats` 计算，`/api/stats` 返回。除特别说明外，统计只计当前有效范围：排除基础词开关、不再学习和有效水平暂缓命中的内容，“今日”按账号时区划分。单词口径与义项口径分开展示，同一处不混用。

| 界面名称 | 字段 | 单位 | 定义 |
|---|---|---|---|
| 今日完成卡片 | `today_completed_cards` | 卡片 | 今日答对并完成的题目回合数，同一回合的错误和订正只算一张 |
| 即刻复习 | `due_words` | 单词 | 现在有到期复习或到点重学义项的单词数 |
| 连续学习 | `streak_days` | 天 | 从今天起向前连续有作答记录的天数，今天未学习时为 0 |
| 已学单词 | `total_learned` | 单词 | 至少开始学习过一个义项的单词数 |
| 学习中的单词 | `learning` | 单词 | 有义项处于 Learning 或 Reviewing、至少答对过一次、且当前没有到期任务的单词数 |
| 可学新词 | `new_words` | 单词 | 所选词库内尚未接触过任何义项的单词数；扩展义按“新内容的顺序”进入 |
| 长期熟记单词 | `mature` | 单词 | 当前范围内的义项全部达到 Mature 的单词数 |
| 总学习时长 | `total_study_time_ms` | 时间 | 全部作答的有效作答时长之和，单题上限 5 分钟，不受范围排除影响 |
| 今日首次作答正确率 | `today_independent_accuracy` | 百分比 | 今日每个回合第一次提交中答对的比例，与学习日历的同名指标一致 |
| 答错过、尚未熟记的单词 | `lapse_words` | 单词 | 有义项答错过且该义项尚未 Mature 的单词数 |
| 已学义项 | `learned_senses` | 义项 | 已开始学习的学习单元数 |
| 进入间隔复习的义项 | `mastered_senses` | 义项 | 状态为 Reviewing 或 Mature 的学习单元数 |
| 待学义项 | `new_senses` | 义项 | 所选词库内尚未开始的学习单元数 |

接口还返回 `mastered`，即当前范围内义项全部进入间隔复习的单词数。它与“进入间隔复习的义项”单位不同、数值差距大，首页不再展示，词库详情的“已掌握”沿用整词口径。新增或调整首页指标时，先在本表写明字段、单位和定义。

## 已修正的边界

2026 年 11 月 2 日移除了日常两天、两个上下文正确就触发 personal_confirmation 暂缓的逻辑。旧个人暂缓记录不再参与有效排除。已经进入标准复习的单元，即使存在历史水平暂缓记录，也继续按照标准调度进入队列。

原规则可能把正常复习日期之后的任务再屏蔽一段时间，形成与记忆模型冲突的第二套调度。后续修改必须覆盖该回归场景。

## 必须保持的行为

- 日常独立答对更新正常记忆与复习安排。
- 两次答对不直接授予长期熟记，也不再触发个人暂缓。
- 短确认的预览、应用和最终有效集合共同排除已有标准复习单元。
- 存在未开始的核心义时，新增学习不派发扩展义，扩展义不计入可学数量。
- 暂缓计数不计入熟记数，部分义项排除不能虚增整词掌握数。
- 服务端在事务内完成作答及关联状态更新。断线重试、旧题提交和跨账号请求分别校验。

核心实现位于 `rust/crates/storage/src/api/study.rs`、`readiness.rs`、`proficiency.rs`，新内容选取与统计位于 `new_unit.sql`、`metrics.sql`，记忆计算位于 `rust/crates/core/`。回归位于 `backend/tests/test_assessment.py` 和原生学习相关测试。
