# 词库与内容模型

## 内容层次

| 对象 | 作用 | 主要存储 |
|---|---|---|
| 词头 | 词典查询、词库组织与整词排除 | words |
| 词汇身份 | 区分词性、屈折、派生及词汇化身份 | lexical_units、word_forms、lexical_relations |
| 来源义项 | 保留原始解释、词性及例句归属 | word_senses、sense_examples |
| 学习单元 | 承接学习、复习与合并后的含义 | learning_units、learning_unit_senses |
| 课程词库 | 组织考试、通用或其他来源的学习范围 | 词库及成员映射表 |
| 账号进度 | 记录用户对学习单元的作答和记忆 | sense_srs_state、adaptive_memory、review_history |

## 内容生产

内容从 Mac 本地词典离线导出，保留词性、解释和例句对应关系。人工覆盖、中文补充、词形关系及语义审核共同维护内容质量。构建产物导入公共词库，用户通过服务器读取。

没有可靠中文对应的义项保留来源信息，无法确定对应关系时进入后续核对。词头相同不能作为不同词典义项可直接合并的充分条件。没有合格例句的内容不直接作为学习题。

词库与课程选择主要约束新增学习。多个词库覆盖同一学习单元时共用学习进度，取消课程选择不取消已有复习。

## 词形与含义

屈折形式可在证据充分时归到同一词汇身份，例如动词原形与过去式。派生词和词汇化形式按自己的身份和可学内容处理。学习单元合并时继承历史关系，已有义项、记录和固定句需保持可追溯。

## 核心义与扩展义

学习单元在内容索引中分为核心义和扩展义，随内容版本在连接内派生，不改变数据库结构。核心义取词头主词典来源里每个词性、每个词典词条按来源顺序排在前两位的可学单元。同形异义词条分别计数，例如 bank 的“岸”与“银行”各自保留。课程范围经人工审核的单元和账号私有内容都算核心义。其余单元为扩展义，在词典和更多词义中照常查阅。

该划分是在义项分级数据完成之前的启发式规则，词典顺序不总等于常用程度。后续以逐义项层级替换时，保持已有进度的承接。

## 固定例句

每个账号与学习单元首次选定有效例句后持续复用，首次优先原形例句。原句失效后才选择替代句。固定例句的长期重复正确属于该上下文的学习证据，水平推断需考虑证据覆盖范围。

## 内容纠错

用户报告附带当前题目和内容快照。管理员审阅来源后修改内容并处理反馈，较大批次可以导出、校验和导入审核结果。修改内容应检查活跃学习单元、当前已签发题目、固定例句和旧进度的承接。

核心义规则位于 `rust/crates/storage/src/api/content_index.sql`。其他代码入口为 `backend/scripts/`、`rust/crates/content/`、`rust/crates/storage/src/api/forms.rs` 和 `lexicon.rs`。具体维护步骤见[语义审核流程](../semantic-review-workflow.md)、[中文翻译流程](../chinese-translation-workflow.md)及[词形审核与计划](../word-morphology-audit-and-plan.md)。
