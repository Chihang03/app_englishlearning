# 界面与交互

## 移动端布局

优先适配 iOS 主屏幕 Web App，检查安全区域、软键盘、视口变化、触摸目标与底部导航。手机浏览器模拟覆盖 320、390、430 像素宽度，真实设备验收另行记录。

首页展示学习概况和入口，学习页集中显示当前例句、输入与释义，设置页管理词库、学习方式、显示、语音、离线内容和账号。离线内容支持查看下载状态、更新与清理，清理不影响学习记录。日历承接长期积累，词典与更多词义承接查阅，管理员拥有单独的工作页面。

## 组件复用

| 元素 | 当前入口 | 要求 |
|---|---|---|
| 导航图标与设置子页页头 | Navigation.tsx | 相同返回图标、按钮尺寸和标题位置 |
| 学习卡片 | StudyCard.tsx | 正在作答与上一题回看使用同一展示结构 |
| 句中输入 | InlineAnswer.tsx | 稳定输入节点、自动尺寸、组合输入保护 |
| 学习卡切换 | StudyDeck.tsx | 指针、滑动、焦点和动画状态一致 |
| 主题 | ThemeSettings.tsx 与 index.css | 跟随系统、浅色、深色 |
| 水平测验 | Assessment.tsx | 介绍、作答、结果、短确认和暂缓列表有清晰操作层级 |

学习方式采用两项点选，选中状态立即反馈，保存期间禁用重复操作，失败后恢复已保存状态。短确认区域放进独立卡片，选择控件与按钮有足够空间。分层成绩逐行对齐，次要操作复用应用按钮样式。

## 反馈与文案

题目错误通过输入区颜色和可访问性状态呈现。网络失败提供明确错误与重试。已由按钮或当前状态表达的信息避免重复增加小字。界面文字使用学习者能够理解的词语，算法和数据库细节留在项目文档。

## 导航与状态

学习者页面使用 hash 导航。返回设置、返回首页、底部导航与浏览器前进后退需要保持一致。账号切换重新挂载学习区域，读缓存按账号隔离。测验恢复会话并保留重试答案，内容更新需要检查缓存失效。

管理员、更多词义和反馈工具分别有自己的状态。它们的入口与是否拥有独立 URL 在[文档导航](../../AGENTS.md)及[页面与接口路由](../项目文档路由表.md)中标明。

## GUI 验收

按真实入口依次检查首页进入测验、设置进入测验、作答、退出恢复、结果应用、短确认、暂缓内容恢复、学习方式保存失败及重复点击。同步检查小屏横向溢出、浅深色、长释义、软键盘和可点击区域。命令构建成功只能证明编译完成，界面行为需浏览器或设备操作验证。
